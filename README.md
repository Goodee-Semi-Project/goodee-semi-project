## Goodee Academy Semi Project - Mungster Class

### 프로젝트 소개

- 반려견 훈련소의 교육 및 일정 관리 서비스입니다.<br>
- 역할에 따라 서로 다른 기능에 접근할 수 있는 것이 핵심으로, 훈련사는 교육과정, 과제, 일정, 출석 현황을 등록 및 관리할 수 있으며, 고객은 회원 가입 후 교육과정의 수강 신청, 과제 제출 등의 기능을 사용할 수 있습니다.

### 개발 기간

- 2025년 6월 25일 ~ 2025년 7월 27일

### 팀 구성

- Goodee Academy GDJ 92기

### 기술 스택

- **Front-End**<br>
HTML, CSS, JavaScript, JSP<br>

Java, Servlet<br>

- **Tools**<br>
Git, GitHub, Eclipse<br>

### 주요 기능

- **회원 관리**<br>
사용자는 로그인 / 로그아웃할 수 있고, 고객은 회원 가입, 정보 수정, 탈퇴를 진행할 수 있습니다.<br>
- **반려견 관리**<br>
고객은 내 반려견을 등록하고 관리할 수 있습니다.<br>
- **교육과정**<br>
훈련사는 교육과정을 관리하고, 고객은 등록된 교육과정을 검색하거나 정보를 확인할 수 있습니다.<br>
- **사전 학습**<br>
훈련사는 사전 학습을 관리하고, 고객은 사전 학습을 진행할 수 있습니다.<br>
- **수강 현황**<br>
고객은 수강 신청, 확인, 수료증 발급을 진행할 수 있고, 훈련사는 수강중인 회원을 관리할 수 있습니다.<br>
- **일정 관리**<br>
훈련사는 오프라인 일정을 등록할 수 있고, 고객은 당일 출석을 체크할 수 있습니다.<br>
- **과제**<br>
훈련사는 과제를 등록할 수 있고, 고객은 등록된 과제를 진행할 수 있습니다.<br>
- **공지사항**<br>
고객을 대상으로 공지사항을 등록 및 관리할 수 있습니다.<br>
- **질문과 답변**<br>
고객은 질문을 등록할 수 있고, 훈련사는 질문에 답변을 남길 수 있습니다.<br>
- **후기**<br>
고객은 수강한 교육과정의 후기를 남길 수 있습니다.<br>
